# rlcard-local

This project extends the RLCard framework by implementing a custom environment for Kings Corner, a multiplayer card game. The project adapts RLCard's existing game architecture to represent Kings Corner's rules, legal actions, game states, player interactions, and win conditions in a format suitable for reinforcement learning experiments.

The implementation focuses on translating the rules of Kings Corner into a structured AI environment where agents can observe game states, select valid actions, and interact through complete game episodes. Modifications to the RLCard framework include custom game logic, state and action representations, legal-move handling, and environment integration.

The project demonstrates the process of transforming a real-world card game into a computational environment that can support reinforcement learning agents and future experimentation with different game-playing strategies.
